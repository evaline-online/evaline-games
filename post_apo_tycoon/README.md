# Evaline Post-Apo Tycoon: Infinite Living Canvas

> **Бесконечный процедурный симулятор выживания и градостроительства (Tycoon / Idle Builder) с двойным отображением: терминальный TUI + интерактивный 2D Canvas (код без ассетов), управляемый Советом из 5 бесплатных LLM-моделей.**

---

## 🌟 Ключевые особенности

1. **Бесконечный процедурный мир (Infinite Canvas):**
   * Мир генерируется математическим мультиоктавным шумом по координатам чанков `(cx, cy)`.
   * Каждый тайл обладает глубокими физическими и экологическими параметрами:
     * **Радиация** (0..100 mSv/h)
     * **Токсичность почв** (0..100%)
     * **Влажность и Плодородие** (гумус, водные артерии)
     * **Биомы:** Радиоактивный кратер, пустошь, мертвый лес, кислотное болото, чистый родник, руины цивилизации, цветущий оазис, ЭВА-заводской комплекс.
2. **2D-графика полностью кодом (Zero Asset Pipeline):**
   * Никаких внешних тяжелых PNG/текстур или фреймворков.
   * Рендер ландшафта, зданий (СЭС, теплицы, барьеры, бункеры), погодных эффектов и радиационных частиц реализован исключительно через Canvas 2D векторные примитивы.
   * Бесконечный зум (колесо мыши), перетаскивание (drag-and-drop) и выбор любого сектора для детального инспектирования.
3. **Терминальный TUI интерфейс:**
   * Полноценный консольный режим с ANSI TrueColor радаром, датчиками ресурсов и логом ходов Совета.
4. **Совет Архитекторов (5 специализированных LLM-Министерств):**
   * **Министр Экологии (Qwen 2.5 72B):** дезактивация радиации, рекультивация почв, очистка болот.
   * **Главный Инженер (DeepSeek Coder / V3):** энергобаланс, производство ЭВА-полимеров, апгрейд фабрик.
   * **Министр Снабжения (Gemini 2.0 Flash):** гидропоника, опреснение воды, распределение пайков.
   * **Верховный Арбитр Социума (Llama 3.3 70B):** наука, мораль поселенцев, защитные ЭВА-экраны.
   * **Архитектор Мироздания / Гейм-Мастер (DeepSeek-R1 / Chaos):** климатические аномалии, разведка новых рубежей и квесты.
   * *Прозрачный фоллбэк:* при отсутствии сети или API-ключа совет автоматически использует интеллектуальную когнитивную эвристику (100% автономность).
5. **Цепочки переработки и ЭВА-полимеры:**
   * Сырье -> Переработка лома -> Экструзия листов ЭВА (EVA polymer sheets) -> Строительство радиационных экранов, изоляции бункеров и модульных теплиц.

## 🚀 Быстрый старт

### 1. Запуск Web-сервера и 2D Canvas (порт 8098)
```bash
cd /home/evabot/evaline-games/post_apo_tycoon
./run.sh web 8098
```
Откройте в браузере: **`http://localhost:8098`** (или через VNC / порт прокси).

### 2. Запуск в Терминале (TUI Radar)
```bash
./run.sh tui
```

### 3. Запуск автоматических тестов
```bash
./run.sh test
```

## 📁 Структура модуля

* [`world_matrix.py`](file:///home/evabot/evaline-games/post_apo_tycoon/world_matrix.py) — процедурный генератор чанков, физика биомов, параметры тайлов.
* [`simulation_engine.py`](file:///home/evabot/evaline-games/post_apo_tycoon/simulation_engine.py) — экономика ресурсов, тики симуляции, амортизация, рекультивация природы.
* [`llm_governors.py`](file:///home/evabot/evaline-games/post_apo_tycoon/llm_governors.py) — совет 5 LLM моделей с вызовами через OpenRouter и когнитивной эвристикой.
* [`terminal_tui.py`](file:///home/evabot/evaline-games/post_apo_tycoon/terminal_tui.py) — ANSI-радар и консольный интерфейс.
* [`web_server.py`](file:///home/evabot/evaline-games/post_apo_tycoon/web_server.py) — REST API сервер.
* [`static/canvas_world.html`](file:///home/evabot/evaline-games/post_apo_tycoon/static/canvas_world.html) — интерактивный HTML5 Canvas интерфейс.
* [`tests/test_post_apo_tycoon.py`](file:///home/evabot/evaline-games/post_apo_tycoon/tests/test_post_apo_tycoon.py) — полный набор юнит-тестов (13 тестов).
